Transfer-matrix counting · a visual walkthrough

How to count every crossword grid without listing a single one

There are 404,139,015,237,875 valid 15×15 American grids. You can’t enumerate them. But you can sweep down the grid one row at a time, merging every partial grid that looks the same at the boundary — and count them all at once.

Companion to the README · code in src/dp.rs & src/british.rs

The object

A grid is a pattern of black & white squares

We’re counting the shapes — where the black squares go — not the letters. A grid is valid (American style) when it has 180° rotational symmetry, every white run across and down is at least 3 long, and all the white squares form one connected region.

The idea · step through it

Sweep down row by row, carrying only the boundary

As we place each row, the only thing the future cares about is the frontier — the last row placed. For each column we remember two things: how long its vertical white run is (capped at 3, since “3 or more” all behave the same) and which columns are connected to each other through the white cells already placed. Why it’s fast

Two different fillings, one frontier — counted together

Because vertical runs are capped at 3, a column that’s been white for four rows looks exactly like one that’s been white for three. So these two different partial grids arrive at an identical frontier. The DP stores that frontier once and adds their counts. This is how 10³⁰ grids collapse into a few million boundary states.

The symmetry trick

Build the top half, mirror it, glue at the center

Every valid grid is its own 180° rotation, so we only ever build the top half. At the center row we fold: each frontier is glued to its own reflection. The vertical run through a column becomes top + center + mirror, which must still be ≥ 3, and the top and bottom components must merge into one region. This gluing step is the fiddliest part of the whole algorithm — the place bugs love to hide.

at the center row

The lower half (faded) is forced — it’s the exact 180° image of the top. Column 3’s run is 2 (top) + 1 (center) + 2 (mirror) = 5 ✓. Columns 0 and 6 close at the center against a black square, with runs of 3 ✓. All the white merges into a single component.

✓ valid — the whole equivalence class is counted at once

The British variant

Cryptic grids add word rules — checked every other letter

British grids drop “every letter checked” and instead require each word of length k to have exactly ⌈k/2⌉ checked letters (cells crossed by a word both ways), with no run of three unchecked in a row. That’s what gives the classic lattice look:

Checked = has a neighbour

Since length-2 runs are banned, a cell is checked exactly when it has a white perpendicular neighbour — so the rule can be tested locally as the sweep passes.

A tiny per-column tally

Each open vertical run carries just three numbers — capped length, checked-minus-unchecked balance, and trailing unchecked count — enough to validate the word at closure.

Same skeleton

Connectivity, symmetry folding and center gluing are identical to the American case; only the run bookkeeping changes.
